Running and compiling different programs, assuming you have the necessary toolchains installed.

These instructions are for Linux and Mac.
On Windows, the shell syntax is a little different and you'll have to add an `.exe` extension to the executables.


## Dynamically typed

### JavaScript
```sh
node example.js
```

### Python
```sh
python example.py
```

## Statically typed

### Java

```sh
javac Example.java
java Example
```

### Go
```sh
go build example.go
./example
```

### Haskell
```sh
ghc example.hs
./example
```
